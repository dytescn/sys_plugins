# manager_workspace

## 定位

项目与工作区管理插件：将 workspace_lib 的项目、特性、版本、日志、设计文件与版本 FFI 整理为 MCP 工具。

底层能力库：`workspace_lib`；端点：`POST http://127.0.0.1:44944/workspace_lib`。

## 调用约定

```http
POST http://127.0.0.1:44944/workspace_lib
Content-Type: application/libary
FFI-Symbol: <symbol>

{}
```

- 响应统一为 `{"code": 200, "data": {}, "msg": "success"}`，`code != 200` 时读取 `msg`。
- 输出缓冲区 64 KiB；超过时 FFI 返回 `-2`，请分页或缩小请求。
- 每个 MCP 工具的 `transport.endpoint` 与 `transport.ffiSymbol` 指向真实 FFI 调用。

## 工具

- 初始化工作区：创建 8 张表与索引；幂等。

- 新建项目：新建项目；name 必填。
- 更新项目：按 id 或 uuid 更新项目白名单字段。
- 删除项目：删除项目；默认软删除，hard=true 时物理删除。

## 使用规则

- 8 个资源统一使用 list / get / create / update / delete 五组接口。
- get / update / delete 的 id 与 uuid 至少提供一个。
- project 是软删除资源；其余资源删除为物理删除。
- list 支持 page / page_size、limit、order 与 filter.keyword。
- save_design 依赖设计软件导出与 libostfil 归档。
